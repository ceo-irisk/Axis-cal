# Axis Calendar iOS App

## Технологический стек
- **React Native** (via Expo SDK 54)
- **React Navigation** — нативная iOS навигация
- **Expo SecureStore** — безопасное хранение токенов (iOS Keychain)
- **Expo Haptics** — тактильная обратная связь
- **Axios** — HTTP клиент для API
- **date-fns** — работа с датами и локализация

## Дизайн
- Тёмная тема (glassmorphism)
- Соответствует веб-версии
- iOS Human Interface Guidelines
