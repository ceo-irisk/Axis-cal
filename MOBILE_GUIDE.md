# 📱 Мобильная версия Axis Calendar

## Структура проекта

```
/app/frontend/src/mobile/
├── components/           # Мобильные компоненты
│   ├── BottomNavigation.jsx   # Нижнее меню навигации (5 кнопок)
│   ├── TwoDayGrid.jsx          # 2-дневная календарная сетка с свайпами
│   └── MonthView.jsx           # Месячный вид календаря
├── pages/               # Страницы мобильного приложения
│   └── MobileCalendarPage.jsx  # Главная страница мобильного календаря
├── hooks/               # Хуки для мобильной версии
│   ├── useIsMobile.js          # Определение мобильного устройства
│   └── index.js
└── index.js             # Главный экспорт мобильных компонентов
```

## Основные функции

### 1. BottomNavigation - Нижнее меню
**Расположение:** Фиксированное внизу экрана
**Порядок кнопок (справа налево):**
1. Настройки (Settings) - крайний левый
2. Календари (Calendars)
3. События (Events)
4. Дашборд (Dashboard) - крайний правый
5. **Сетка (Grid)** - появляется динамически когда открыта вкладка сайдбара

### 2. TwoDayGrid - 2-дневная сетка
**Особенности:**
- Показывает 2 дня рядом
- Поддержка **свайпов** влево/вправо для навигации:
  - Свайп влево → следующие 2 дня
  - Свайп вправо → предыдущие 2 дня
- Минимальная дистанция свайпа: 50px
- События отображаются как цветные блоки на временной шкале (24 часа)
- Клик на пустое место → создание нового события

### 3. MonthView - Месячный календарь
**Особенности:**
- Полный месячный календарь
- Точки под датами показывают наличие событий (до 3 точек)
- Клик на дату → переключение на 2-дневный вид с этой датой
- Навигация между месяцами стрелками

### 4. Переключатель видов
Кнопки в шапке:
- **"2 дня"** - переключение на 2-дневную сетку
- **"Месяц"** - переключение на месячный вид

## Интеграция с основным приложением

Мобильная версия автоматически активируется при ширине экрана < 768px.

### В CalendarPage.jsx:
```jsx
import { MobileCalendarPage } from '../mobile';
import { useIsMobile } from '../mobile/hooks';

// ...

const isMobile = useIsMobile();

if (isMobile) {
  return <MobileCalendarPage {...props} />;
}

// Desktop version
return <DesktopLayout />;
```

## Технические детали

### Свайпы
Реализованы через нативные touch events:
- `onTouchStart` - запоминаем начальную точку
- `onTouchMove` - отслеживаем движение
- `onTouchEnd` - вычисляем дистанцию и направление

### Адаптивность
- Использует Tailwind CSS breakpoints
- Mobile-first подход
- Фиксированное нижнее меню (z-index: 50)
- Полноэкранный контент (высота минус хедер и нижнее меню)

### События
- Поддержка всех типов событий (confirmed, tentative, template)
- Цветовая кодировка по типам событий
- Визуальные индикаторы (border для tentative/template)

## Будущее использование

Эта структура специально создана для:
- **React Native** приложения (iOS/Android)
- **Capacitor/Ionic** обёртки
- **PWA** (Progressive Web App)

Компоненты изолированы и могут быть легко переиспользованы в нативных приложениях с минимальными изменениями.

## Тестирование

Для тестирования мобильной версии:
1. Откройте DevTools (F12)
2. Включите режим мобильного устройства (Ctrl+Shift+M)
3. Выберите устройство (iPhone X, Pixel, etc.)
4. Обновите страницу

Или измените ширину окна браузера до < 768px.
