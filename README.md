## Фичи

### Шаблоны дней

У каждого из нас есть дни которые идут одинаково. А почему нет функционала создания событий из шаблона?
Можно создать шаблон дня и загружать его в день, таким образом очень легко заполнять свой календарь типовыми соыбтиями, а так же быстро перестраивать календарь под какие-то экстренные изменения

### Типы событий вместо календарей

Долой диктатуру календарей где для нового цвета события надо новый календарь создавать. Даешь типы событий. Теперь Есть справочник типов событий на основании которого к событию применяется цвет.

### Календари для прав доступа

У меня есть такие события которые я не хочу показывать кому-либо, а есть те, которые я хочу чтобы видели. Для этого можно настроить права доступа пользователей к календарям. У каждого юзера предсоздано 2 календаря (Открытый и закрытый) А права есть 4 типов: Занятость, Просмотр, Редактирование, Полный доступ

### Статусы событий

У меня есть такие события которые вроде будут, а вроде и нет. А как их отличить от тех которые точно будут? Вот тебе) 3 Статуса события:
1. Обычное событие - точно будет
2. Возможное событие - отображается пунктирной линией вокруг
3. Шаблонное событие - шоб было видно что оно из шаблона. (Нажми на него 2 раза и оно станет обычным)

### Флаги / Иконки для событий

Вот есть у меня созвон с партнером. А это созвон по зуму или по телефону? А как понять что событие срочное? Вот держи иконки. Они помогут понять что-то важное об этом событии

### Правила дня
