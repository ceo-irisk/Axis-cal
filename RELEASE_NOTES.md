# Release Notes - Axis Calendar

## 🎯 Основные доработки

### 1. Управление календарями
- ✅ **Убрано поле color из календарей** - теперь используются только цвета типов событий
- ✅ **Дефолтные календари** - автоматическое создание "Открытый" и "Закрытый" для новых пользователей
- ✅ **Кнопка создания календаря** - добавлена на второй вкладке сайдбара
- ✅ **Настройка прав доступа** - кнопка управления доступом доступна для всех календарей прямо на второй вкладке

### 2. Система прав доступа
- ✅ **4 уровня доступа к календарям:**
  - `view_busy` - Только занятость (видно только "Занято")
  - `read` - Чтение (просмотр событий)
  - `edit` - Редактирование (просмотр + изменение)
  - `full` - Полный доступ (просмотр + изменение + удаление)
- ✅ **Удален модуль подписок на пользователей** - осталась только система permissions
- ✅ **События "Занято"** - визуально оформлены серым цветом, нельзя редактировать
- ✅ **Полные права** - теперь позволяют удалять события других пользователей

### 3. Структура сайдбара (вкладка 2)
**Возвращены календари вместо подписок:**
- 📅 **Мои календари** - с кнопкой создания и управления правами
- 👥 **Доступные мне** - расшаренные через permissions
- 🌐 **Внешние календари** - ICS подписки с кнопкой добавления

### 4. Часовые пояса
- ✅ **Удалена автоподгрузка из браузера**
- ✅ **Поле timezone добавлено:**
  - В модель User (выбор при создании/редактировании пользователя)
  - В модель Event (сохраняется timezone в момент создания)
- ✅ **Отображение с учетом смещения** - события показываются с учетом их timezone
- ✅ **Текущее время** - показывает реальное локальное время пользователя

### 5. Внешние календари (ICS)
- ✅ **Конвертация webcal://** - автоматическая конвертация в https://
- ✅ **Поддержка Apple Calendar** - корректная обработка webcal:// ссылок
- ✅ **Тип события "Внешнее событие"** - все ICS события получают тип "external"
- ✅ **Статус "template"** - ICS события по умолчанию шаблонные
- ✅ **Отображение источника** - в форме редактирования показывается название календаря
- ✅ **Скрытие ICS календарей** - кнопка глаза работает для внешних календарей

### 6. Повторяющиеся события
- ✅ **Объединение в один эндпоинт** - `/api/events?expand_recurring=true`
- ✅ **Параметр expand_recurring** - управление генерацией instances
- ✅ **Исправлено время** - instances повторяются в то же время что и parent
- ✅ **Поддержка типов recurrence:**
  - daily - каждый день
  - workdays - рабочие дни (Пн-Пт)
  - weekly - каждую неделю
  - monthly - каждый месяц
  - yearly - каждый год
  - custom_days - определенные дни недели
- ✅ **Иконка Repeat** - визуальный индикатор повторяющихся событий

### 7. Функциональность скрытия календарей
- ✅ **Исправлена кнопка глаза** - добавлен state `hiddenCalendars` в CalendarPage
- ✅ **Фильтрация событий** - события из скрытых календарей не показываются
- ✅ **Поддержка ICS** - фильтрация работает и для внешних календарей
- ✅ **useEffect оптимизация** - исправлен React warning

### 8. Переключение пользователей
- ✅ **Dropdown в шапке** - быстрое переключение между пользователями
- ✅ **Автоматический логин** - при клике происходит логин и reload страницы
- ✅ **Корректные пароли** - admin123 для админа, user123 для пользователя

### 9. UI/UX улучшения
- ✅ **Убраны уведомления о создании** - остались только ошибки
- ✅ **Унифицированные сообщения** - "Недостаточно прав" вместо разных текстов
- ✅ **Блоки всегда видны** - "Доступные мне" и "Внешние календари" показываются даже если пусты
- ✅ **Серая точка для "Занято"** - в сайдбаре события "Занято" с серой точкой

### 10. Настройки (вкладка 4)
- ✅ **Убраны дубликаты** - удалены вкладки "Мои календари" и "ICS"
- ✅ **Оставлены только:**
  - Пользователи (для админов)
  - Шаблоны
  - Справочники
  - Профиль

## 🐛 Исправленные баги

1. **ObjectId serialization** - MongoDB _id не попадает в ответ API
2. **Дефолтные календари не создавались** - исправлена логика создания
3. **Кнопка скрытия календарей** - crash из-за отсутствия onHiddenCalendarsChange
4. **Текущее время** - показывалось неправильно с лишним offset
5. **Переключение пользователей** - неправильные пароли
6. **Редактирование типов событий** - ошибка при изменении цвета
7. **Применение шаблонов** - ошибка парсинга даты
8. **События шаблона** - создавались в неправильное время
9. **Recurring events 520 error** - отключен вызов /api/recurring-events
10. **Время повторяющихся событий** - UTC конвертация сдвигала время
11. **TypeError в recurrence.py** - datetime vs string обработка

## 📝 Модульная архитектура

Проект сохраняет модульную структуру:
- `backend/routes/` - разделенные роуты (auth, users, events, calendars, templates, etc)
- `backend/services/` - бизнес-логика (permissions, recurrence, init_data)
- `backend/models/` - Pydantic модели
- `frontend/src/components/` - переиспользуемые компоненты
- `frontend/src/pages/` - страницы приложения
- `frontend/src/lib/` - утилиты и API клиент
