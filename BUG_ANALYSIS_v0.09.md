### ПРИОРИТЕТ 1 (КРИТИЧЕСКИЙ):

#### 🔧 1.1 Исправить инициализацию часовых поясов

**Файл**: `backend/services/init_data.py`

**Проблема**: 
```python
timezones = [
    {"id": str(uuid.uuid4()), "name": name, "label": f"{name}"},
    ...
]
# label становится None вместо строки
```

**Решение**:
```python
# Правильная инициализация с русскими названиями
timezone_data = [
    ("Europe/Moscow", "Москва"),
    ("Europe/London", "Лондон"),
    ("America/New_York", "Нью-Йорк"),
    ...
]

timezones = [
    {
        "id": str(uuid.uuid4()), 
        "name": tz_name, 
        "label": tz_label,
        "offset": "+03:00",  # Или рассчитывать динамически
        "is_active": True,
        "created_at": datetime.now(timezone.utc).isoformat()
    }
    for tz_name, tz_label in timezone_data
]
```
